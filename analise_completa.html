📄 1. Resumo do PascalCoin (pascal.pdf v5.0)

Whitepaper de setembro/2019 por Herman Schoenfeld e Albert Molina. Pascal é uma criptomoeda "next-generation" com foco em escalabilidade infinita.

CaracterísticaPascalCoin Original
ModeloAccount-based (PASA), não UTXO
ConsensoProof-of-Work (RandomHash2, GPU/ASIC resistente)
EstruturaSafeBox (ledger balance) + Blockchain (ledger)
Blockchain deletávelSim — só últimos 100 blocos necessários (“infinite scaling”)
Supply total42M PASC, halving a cada 2 anos, tail emission 1 coin/bloco
Bloco5 minutos, ~5 contas por bloco
TaxasZero-fee (1 tx grátis por bloco, 288/dia)
EndereçosNúmeros legíveis (ex: 1234-56), nomes únicos (DNS-like)
SegurançaECDSA, Double-Spend Alerts, Coin-rot recovery (4 anos)
Layer-2OP_DATA, atomic swaps, embedded chains
GovernançaBlock Policy (v6 planejada), 20% developer reward
Throughput1,600 TPS (VISA-level)

📚 4. Análise por Crate

4.1 augecoin-crypto

  • ✔ Ed25519: geração, assinatura e verificação (ed25519-dalek 2)
  • ✔ BLAKE3-512 XOF: hash determinístico
  • ✔ HD Wallet: BIP39 + HKDF-SHA3-512
  • ✔ Bech32m: derivação e validação (prefixo auge1)
  • ✔ WASM bindings (wasm-bindgen)
  • ⚠ Dilithium removido — HybridSignature = alias para Ed25519

Dependências

bech32 0.12, bip39 2, blake3 1, ed25519-dalek 2, hex 0.4, hmac 0.12, rand 0.8, serde 1, serde_json 1, sha3 0.10, wasm-bindgen 0.2

4.2 augecoin-core

  • ✔ Account: balance, n_operation, name, type, data, seal
  • ✔ Transaction: 6 variantes (Transfer, ChangeKey, ClaimAccount, SetAccountName, AttachData, ValidatorAdmin)
  • ✔ Operation (PascalCoin-compatível): 11 tipos com serialização binária
  • ✔ Block/BlockHeader: Merkle root de operações, serialização canônica
  • ✔ SafeBox: BTreeMap + name_index + Merkle hash
  • ✔ Emission: 29 AUGE/bloco, 50 anos, 762.12M total, proptest verificado

Constantes Monetárias

Block reward29 AUGE (2.9B augesat)
Block time60 segundos
Emission period50 anos (26.28M blocos)
Total supply762.120.000 AUGE
1 AUGE100.000.000 augesat
Contas/bloco10 (CT_ACCOUNTS_PER_BLOCK)
Premine0%
Dev reward0%

4.3 augecoin-storage

  • ✔ RocksDB com 6 Column Families: accounts, blocks, safebox, op_index, validator_set, equivocation_proofs
  • ✔ CRUD completo para contas, blocos, SafeBox, validators, equivocation proofs
  • ✔ Checkpoints: capture/restore com formato versionado (v1)
  • ✔ State root via Merkle tree binária sobre todas as contas
  • ✔ Rollback, detecção de corrupção (checksum BLAKE3), recovery de checkpoint

4.4 augecoin-consensus

  • ✔ ValidatorSet: add/remove/activate/deactivate com activation_height futuro
  • ✔ Leader selection: round-robin determinístico (height % len)
  • ✔ RoundState: Propose → Verify → Sign → Commit + timeout + view-change
  • ✔ Quórum 2/3+1: (n * 2) / 3 + 1
  • ✔ Equivocation: detecção + EquivocationProof com duas assinaturas conflitantes

4.5 augecoin-network

  • ✔ Transporte libp2p com TCP + Noise encryption + Yamux multiplexing
  • ✔ Gossipsub para propagação de operações e blocos
  • ✔ Bootnodes estáticos + autenticação de validator peer
  • ✔ Fast sync: checkpoint + replay de blocos restantes
  • ✔ Rate limiting: banimento temporário por violações repetidas

4.6 augecoin-rpc

  • ✔ JSON-RPC 2.0 sobre TLS (axum + rustls) — HTTP puro rejeitado
  • ✔ 16 métodos: getaccount, getblock, getblockoperations, sendoperation, getpendings, findaccounts, nodestatus, validatoradd/remove/activate/deactivate, ping, etc.
  • ✔ Auth: API keys com níveis Public/Admin
  • ✔ Rate limiting por IP/API key (token bucket)
  • ⚠ gRPC: apenas health.proto (scaffold, sem endpoints de negócio)

4.7 augecoin-node

  • ✔ Mempool: valida assinatura, n_operation, saldo, fee, duplicatas
  • ✔ execute_block() atômico: 6 fases com rollback em HashMap se falhar
  • ✔ ConsensusEngine: loop de consenso TCP-based entre validadores
  • ✔ 6 métricas Prometheus: block_height, block_time, peers, mempool, equivocation, latency
  • ✔ AlertManager: equivocation, malicious peer, validator absent, replay attempt + webhook

4.8 augecoin-cli

  • ✔ Comandos validator: list, add, remove, activate, deactivate, earnings
  • ✔ Comandos status: altura, peers, sincronização, saúde do quórum
  • ✔ Comandos security: equivocations, banned-peers, alerts (--tail)
  • ✔ Comandos de conta: get-account, get-block, send-operation, get-pendings, find-accounts
  • ✔ Output tabular (Unicode) ou JSON, shell completions (clap)
  • ✔ RpcClient com TLS + signing de operações admin via mnemonic/HD wallet

⚖ 7. Veredito Final

Status: ~85% — Testnet Fechada ✔ | Mainnet ✘

O código do AugeCoin está funcional, compila sem erros, passa em 269 testes Rust com 0 falhas, e possui cobertura de cenários críticos de consenso, storage e rede. É uma reimplementação substancial do PascalCoin em Rust com várias melhorias (RPC sobre TLS, métricas Prometheus, SDK TypeScript, 3 wallets), mas com mudanças arquiteturais fundamentais que o tornam um protocolo diferente, não um fork compatível.

✅ O que está PRONTO

  • ✔ Core de criptografia (Ed25519, BLAKE3, HD keys, Bech32m)
  • ✔ Data model completo (Account, Transaction, Block, SafeBox)
  • ✔ Emissão monetária verificada (proptest)
  • ✔ Storage robusto (RocksDB, 6 CFs, checkpoints, rollback)
  • ✔ Consenso BFT funcional (4 validadores, quórum, equivocation)
  • ✔ Rede P2P (libp2p + Noise + gossipsub + sync)
  • ✔ RPC completo (16 métodos JSON-RPC 2.0/TLS)
  • ✔ Execução atômica de bloco (E2E, load, partition testados)
  • ✔ Métricas Prometheus + Grafana
  • ✔ CLI completo (validator, status, security, earnings)
  • ✔ Docker compose testnet 4 nós
  • ✔ 3 wallets (web, desktop, mobile)
