Fundação Criptográfica

Assinatura híbrida obrigatória desde o bloco gênesis — ambas as assinaturas devem verificar.

🔐 Assinatura Híbrida

Ed25519 (clássica, 64 bytes) + ML-DSA-65 / CRYSTALS-Dilithium (pós-quântica, NIST FIPS 204, 3309 bytes). Transação ou bloco só é válido se ambas as assinaturas verificarem.

#️⃣ Hash BLAKE3-512

Modo XOF com saída de 512 bits. Usado para hash de estado, bloco, transação e derivação de endereços. Mais rápido que SHA-256 com segurança equivalente.

🔑 HD Wallet (HKDF-SHA3-512)

Derivação determinística: seed BIP39 → HKDF-SHA3-512 → sementes por índice → par Ed25519 + Dilithium. Vetores de teste fixos garantem reprodutibilidade Rust ↔ TypeScript ↔ Mobile.

🏷️ Endereços Bech32m

Prefix auge1... com checksum. Derivados de blake3_512(ed25519_pk || dilithium_pk). Validação rigorosa com detecção de erros de digitação.

🔄 Crypto Agility

Campo sig_scheme_version em cada transação permite trocar/adicionar esquemas de assinatura via hard fork governado pelos validadores.

Consenso Proof-of-Authority

Rede permissionada com 4 validadores iniciais, seleção de líder round-robin determinística e finalidade por quórum.

👥 ValidatorSet

Estado on-chain com add/remove/activate/deactivate via operação ValidatorAdmin assinada pela chave administradora. activation_height futuro obrigatório — mudanças nunca são imediatas.

🎯 Líder Round-Robin

leader_for_height(h) = active_validators[h % active_validators.len()]. Seleção 100% determinística, previsível e auditável.

✅ Máquina de Estados

Ciclo Propose → Verify → Sign → Commit com timeout configurável (padrão 120s = 2× block time). ViewChange automático para o próximo validador se o líder não propõe a tempo.

⚖️ Quórum 2/3+1

3 de 4 assinaturas válidas finalizam um bloco. Se <3 validadores ativos, blocos não são finalizados — fail-safe contra partição de rede.

🚨 Detecção de Equivocation

Duas assinaturas do mesmo validador na mesma altura geram EquivocationProof on-chain. Validador marcado como slashable, removível pelo administrador.

Emissão Monetária

100% do suprimento gerado via recompensa de bloco. Zero pré-mineração. Propriedade matemática verificada por proptest.

🪙 Regra de Emissão

BASE_REWARD = 75.000.000.000.000.000 / 26.298.000
           = ~2,85 bilhões augesat por bloco

Restante distribuído como +1 augesat
nos primeiros REMAINDER_AUGESAT blocos

Após bloco 26.298.000 → recompensa 0

📊 Verificação Formal

Teste proptest soma block_reward(h) para h = 1..26.298.000 e verifica que o total é exatamente 75.000.000.000.000.000 augesat — nem 1 a mais, nem 1 a menos.

Rede P2P

🔒 Transporte libp2p + Noise

Criptografia obrigatória via Noise Protocol. Conexão sem Noise é rejeitada. Handshake criptográfico entre peers.

📢 Gossipsub

Propagação de transações e blocos via tópicos gossipsub. Mensagem malformada não derruba o nó.

🛡️ Autenticação de Canal

Só nós com chave de validador reconhecida participam do canal de consenso. Observadores só recebem dados públicos via RPC.

⚡ Fast Sync

Sincronização inicial via checkpoint mais recente + replay dos blocos restantes. Sync interrompido pode ser retomado sem corromper o estado.

🚫 Rate Limiting & Banimento

Contador de infrações por peer. Banimento temporário configurável. Peer bem comportado nunca é afetado. Ban expira automaticamente.

API RPC

📡 JSON-RPC 2.0 sobre TLS

Servidor JSON-RPC 2.0 com TLS obrigatório. Conexão HTTP pura rejeitada em produção. Porta padrão: 9443.

🔌 gRPC sobre TLS

Servidor gRPC com TLS para clientes de alta performance. Health check service incluído.

🔑 Auth & Rate Limiting

API key para endpoints administrativos. Rate limiting por IP/API key via token bucket. Endpoints públicos não exigem autenticação.

📋 Endpoints

  • getAccount — consultar conta por número
  • getBlock / getBlockByHeight
  • sendTransaction — enviar transação assinada
  • getMempool — transações pendentes
  • getValidatorSet — validadores ativos
  • getNetworkStatus — altura, peers, sync
  • getValidatorEarnings — ganhos por validador

Wallets

Três wallets oficiais. Nenhum dado sensível (seed/chave privada) sai do dispositivo.

🌐 Wallet Web

React 19 + TypeScript + Vite. WASM crypto. Fluxo completo: seed BIP39 12 palavras (exibida 1× com confirmação), verificação (digitar palavra N), senha (mín 8 chars).
Keystore: IndexedDB + PBKDF2-SHA256 (600k iters) + AES-256-GCM. QR code Bech32m.

🖥️ Wallet Desktop (Tauri)

Rust nativo + React. Crypto via augecoin-crypto diretamente (sem WASM).
Keystore: Keychain (macOS) / Credential Manager (Windows) / libsecret (Linux).

📱 Wallet Mobile (React Native)

Expo SDK 52. Módulo nativo para operações criptográficas.
Keystore: Secure Enclave (iOS) / Android Keystore + PBKDF2-SHA256 + AES-256-GCM. QR code nativo.

CLI Administrativa

Interface de linha de comando completa com saída tabular Unicode e --json. Autocomplete de shell via clap.

👥 Validator

augecoin-cli validator list [--json]
augecoin-cli validator add --ed25519-key ... \
    --ml-dsa-key ... --activation-height N
augecoin-cli validator remove --id N
augecoin-cli validator activate --id N
augecoin-cli validator deactivate --id N

Admin commands exigem --mnemonic. Transação assinada localmente com Ed25519 + Dilithium.

📊 Status & Earnings

augecoin-cli status [--json]
augecoin-cli validator earnings --all [--json]
augecoin-cli validator earnings --id N

Status: altura, peers, sincronização, saúde do quórum. Earnings: ranking por total AUGE ganho (recompensa + taxas).

🛡️ Security

augecoin-cli security equivocations
augecoin-cli security banned-peers
augecoin-cli security alerts --tail

Equivocations: provas registradas. Banned-peers: lista de banidos. Alerts --tail: stream em tempo real (equivocation, peer malicioso, replay).

🚨 Alertas Ativos

  • Equivocation: nível Critical — validador assinou 2 blocos na mesma altura
  • Malicious Peer: nível Warning — infrações repetidas, auto-ban
  • Validator Absent: nível Warning — líder não propôs dentro do timeout
  • Replay Attempt: nível Info — op_sequence reutilizado

Webhook genérico configurável (Slack/Discord/Telegram). Log estruturado via stderr.

SDK TypeScript

📦 @augecoin/wasm-crypto

augecoin-crypto compilado para WASM via wasm-pack. Expõe geração de chaves, assinatura e verificação para JavaScript/TypeScript.

🧰 @augecoin/sdk

SDK de alto nível: criação de carteira HD, assinatura de transação, chamadas RPC tipadas (geradas a partir do .proto gRPC), utilitários de formatação de saldo (augesat ↔ AUGE).

🔬 Paridade de Vetores

Mesmos vetores de teste fixos (hdkeys.json) usados para confirmar que a derivação de chave em TypeScript bate byte-a-byte com Rust. Reprodutibilidade garantida entre todas as plataformas.

Segurança & Hardening

🎯 Fuzzing

  • tx_deserialize: 5.4M iterações, 0 crashes
  • block_deserialize: 287K iterações limpas (bug OOM encontrado e corrigido: bounds checks em tx_count e qs_count)

⚡ Load Test

  • 36-38 tx/s sustentado
  • Bloco de 1000 transações: 27s (limite: 60s)
  • Bloco de 500 transações: 14s

🔀 Partição de Rede

  • 2/4 validadores isolados: quórum não atingido (fail-safe)
  • 3/4 validadores: finalização normal
  • Atomicidade preservada durante recuperação
  • State root consistente pós-partição

🔒 TLS Everywhere

  • JSON-RPC sobre TLS (rejeita HTTP puro)
  • gRPC sobre TLS
  • libp2p + Noise para P2P
  • API keys para endpoints admin
  • Rate limiting token-bucket
